## 이 폴더에 대해

**Builders Lounge 모임에서 발표한 사람과 그 제품을 사람별로 정리한 곳이다.**

모임 회차별 기록(`videos/`)은 "그날 무슨 일이 있었나"를 담고, 이 폴더는 **"이 사람이 무엇을 만들고 있나"** 를 담는다. 같은 사람이 여러 회차에 걸쳐 발표하는 경우가 많아 회차 기록만으로는 한 제품의 전체 흐름을 따라가기 어렵기 때문이다.

각 폴더에 `profile.md` 하나가 기본이고, 발표 자료나 이미지가 있으면 `materials/` · `assets/images/` 에 함께 둔다.
