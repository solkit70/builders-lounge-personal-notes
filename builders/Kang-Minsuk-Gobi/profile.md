## 한 줄 소개

**스타트업 창업자.** AI 네이티브 소셜 공간 **Gobi Space**와 안경형 웨어러블을 개발 중이며, Builders Lounge 커뮤니티 에이전트 **Bila AI**를 박창수와 함께 만들고 있다. 1차 모임 hands-on 진행자.

## 제품

### Gobi Space

**AI 네이티브 소셜 공간.** 사람과 AI 에이전트가 같은 공간에서 글과 댓글을 주고받는다.

| 항목 | 내용 |
| --- | --- |
| 웹사이트 | https://www.gobispace.com/ |
| 구성 | Gobi Space (웹·앱) · Gobi Desktop · Gobi CLI |
| 핵심 개념 | Vault 기반 포스팅 · Space Agent · 개인 Agent |
| 연동 | GitHub · Drive · Slack |

**자사가 Slack을 끊고 Gobi Space로 업무를 옮긴 상태**라고 4차 모임에서 밝혔다. 채널에 에이전트를 태그해 업무를 요청하면 답변이 달리는 구조다.

### Bila AI Agent

**창발 Space의 글과 GitHub 저장소 기록을 참조해 Builders Lounge 관련 질문에 답하는 에이전트.** 박창수와 함께 만들고 있다.

4차 모임에서는 **개회 진행을 Bila AI에게 맡겼다.** 시작 직후 할루시네이션이 발생해 즉석에서 지적받았는데, 이를 숨기지 않고 그대로 노출했다. 완성 후 공개가 아니라 **미완성 상태로 사용자 앞에 세우는** 방식이다.

4차 모임에서 **모바일 앱 출시 소식**까지 나왔다.

### 안경형 웨어러블 (개발 중)

컨퍼런스 부스 대화를 캡처해 자동으로 고객 관리(CRM)를 돕는 하드웨어. 프라이버시 이슈 때문에 **우선 공개된 컨퍼런스 환경부터 침투**하는 전략이라고 3차 Coffee Chat에서 밝혔다.
