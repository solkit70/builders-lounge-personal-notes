## 개요

미국에 살면서 미국인들의 행사, 토론, 회의, 일상 대화에 참여할 일이 많기 때문에, 한국어 사용자 입장에서 실시간으로 영어 대화를 이해하고 나중에 다시 활용할 수 있는 번역 앱이 필요하다. 지금 바로 개발하지는 않고, 앞으로 개발할 개인/Builders Lounge 백로그 아이디어로 보관한다.

## 문제 인식

- 행사나 회의에서 영어 대화를 실시간으로 따라가야 하는 상황이 많다.
- 단순 번역만으로는 부족하고, 누가 어떤 말을 했는지 화자 구분이 필요하다.
- 대화가 끝난 뒤에는 번역문만이 아니라 핵심 내용, 결정사항, 후속 action item을 요약해 두고 싶다.
- 컴퓨터와 모바일 폰 양쪽에서 사용할 수 있어야 실제 행사장, 회의실, 온라인 미팅에서 모두 활용 가능하다.

## 제품 아이디어

실시간 음성 입력을 받아 화자를 구분하고, 영어 대화를 한국어로 실시간 번역하며, 세션 종료 후 대화 요약과 action item을 생성하는 앱을 만든다. 초기 버전은 개인 사용을 목표로 하되, Builders Lounge 같은 커뮤니티 모임이나 한미 협업 회의에서도 활용 가능한 방향으로 확장한다.

## 핵심 기능 후보

| 기능 | 설명 |
|---|---|
| 실시간 음성 전사 | 마이크 입력 또는 회의 오디오를 실시간 텍스트로 변환 |
| 실시간 번역 | 영어 발화를 한국어로 즉시 번역하고, 필요하면 한국어 발화를 영어로 번역 |
| 화자 구분 | 참석자별 발언을 분리해 Speaker 1, Speaker 2 또는 이름으로 표시 |
| 세션 기록 | 원문, 번역문, 타임스탬프, 화자 정보를 함께 저장 |
| 회의 후 요약 | 핵심 주제, 결정사항, 질문, action item, follow-up 대상 생성 |
| 크로스 플랫폼 | desktop web/app과 mobile phone 사용을 모두 고려 |

## 초기 MVP 범위

1. 모바일 또는 노트북 마이크에서 실시간 영어 음성을 받아 전사한다.
2. 한국어 번역을 지연이 크지 않은 형태로 화면에 표시한다.
3. 최소한의 화자 구분을 제공한다. 초기에는 자동 이름 인식보다 Speaker 1/2/3 수준으로 시작한다.
4. 세션 종료 후 원문/번역문/요약/action item을 Markdown 또는 JSON으로 export한다.
5. 개인정보와 녹음 동의 이슈를 UI에서 명확히 안내한다.

## 기술 검토 메모

- OpenAI `gpt-live-transcribe`는 실시간 저지연 전사 후보로 검토한다.
- 완료된 녹음 파일의 후처리/정밀 재전사는 `gpt-transcribe` 후보로 검토한다.
- 화자 구분은 실시간 모델만으로 부족할 수 있으므로 diarization 전용 모델, 오디오 채널 분리, 또는 후처리 파이프라인을 별도로 검토한다.
- 미국 행사/회의 맥락에서는 녹음 동의, 민감정보, 저장 기간, 로컬 저장 여부를 초기 설계부터 고려한다.

## Backlog 상태
